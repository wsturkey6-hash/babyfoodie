# babyfoodie

> **已整合進 [BabyMonster](https://github.com/wsturkey6-hash/BabyMonster)，本專案不再維護。**
>
> 副食品紀錄與試敏表現在是 BabyMonster 的「副食品」分頁，多了兩位家長同步、多寶寶與備份。
> 這個網站（GitHub Pages）已於 2026-10-30 關閉；當初存在瀏覽器裡的資料沒有搬過去。

紀錄寶寶開始嘗試副食品的網頁。

- **紀錄**：日期、時間、副食品內容、份量、觀察記錄
- **試敏表**：4～10 個月可嘗試的食材與建議嘗試順序，嘗試過的食材會用不同顏色標示
- **寶寶資料**：輸入名字、生日，計算目前幾個月

規格見 [SPEC.md](SPEC.md)（BabyMonster 的試敏表食材清單就是照這份搬過去的），開發規範見 [CLAUDE.md](CLAUDE.md)，進度見 [PROGRESS.md](PROGRESS.md)。
BabyMonster 那邊的設計文件：[docs/superpowers/specs/2026-10-29-baby-food-design.md](https://github.com/wsturkey6-hash/BabyMonster/blob/main/docs/superpowers/specs/2026-10-29-baby-food-design.md)。
